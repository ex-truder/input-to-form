# Панели параметров HDA на сайте

Компонент читает два файла формата v1 из `tools/houdini/hda_export.py`, показывает
вычисленные значения и синхронизирует их с HTML-видео. Настройки отображения
хранятся в конфигурации кейса, отдельно от экспорта Houdini.

## Локальный предпросмотр

Запусти `npm run dev` и открой `/#/ru/hda-preview` на адресе Vite.
Страница доступна только в режиме разработки и не входит в production build.

Экспорт из `houdini-exports.local` подхватывается автоматически. Если экспортов
несколько, первым загружается комплект по алфавиту; другой можно выбрать кнопкой
«Выбрать JSON». В файловом диалоге выбери сразу `*.parameters.json` и
`*.animation.json`. Дополнительный `report.json` не требуется.

Без видео можно проигрывать шкалу параметров и перематывать её. Кнопка «Выбрать
видео» подключает локальный файл: панель начинает следовать его времени.
Файлы выбираются через браузер и остаются локальными; код предпросмотра не
отправляет их на сервер. После обновления страницы видео нужно выбрать снова.

Можно настроить:

- Ноду, набор полей и учёт скрытия полей в Houdini.
- Таблицу или карточки, тёмную или светлую тему, акцентный цвет.
- Минимальную высоту строки таблицы от 24 до 120 px.
- Панель справа, слева, под видео или поверх него; угол и ширину.
- Преобразование значений RGB из linear в sRGB при необходимости.
- Секунду видео, соответствующую первому кадру экспорта.

В разделе «Подключение в кейс» формируется готовый блок настроек. Скопируй его
и замени `my-case` и путь к видео. Настройки страницы не сохраняются автоматически.
Компонент в публичном кейсе отображает значения без элементов управления ими;
настройки и выбор файлов относятся только к локальному предпросмотру.

## Подключение в страницу проекта

Помести нужный комплект в `public/projects/<slug>/` рядом с видео. Добавь объект
в массив `blocks` соответствующего проекта в `src/data/projects.js`:

```js
{
  type: "hdaDemo",
  title: { ru: "Управление формой", en: "Shape controls" },
  parameters: "/projects/my-case/buildingHDAdemo.parameters.json",
  animation: "/projects/my-case/buildingHDAdemo.animation.json",
  video: {
    src: "/projects/my-case/demo.mp4",
    poster: "/projects/my-case/cover.png",
    controls: true,
    loop: true,
    autoPlay: false,
    muted: true,
    fit: "contain",
  },
  sync: { videoStart: 0, sourceStart: 0, speed: 1 },
  panels: [{
    node: "/stage/buiding/sopnet/create/residental_building",
    title: { ru: "Параметры здания", en: "Building parameters" },
    placement: "right",
    width: 340,
    theme: "dark",
    accent: "#ff6633",
    variant: "table",
    showHidden: true,
    fields: [
      { name: "base_size", label: { ru: "Размер основания", en: "Base size" }, unit: "m", precision: 1 },
      { name: "rows", label: { ru: "Ряды секций", en: "Section rows" } },
      "cols",
      "floors",
      { name: "bias", label: "Cascade spin", view: "bar", min: 0, max: 10 },
      "ramp",
    ],
  }],
}
```

Пути обрабатываются через существующий `publicAsset()`, включая base URL сборки.
`report.json` для сайта не нужен. JSON из папки `houdini-exports.local` не
копируется в публичную сборку автоматически.

## Настройки панели

| Поле | Значение |
| --- | --- |
| `node` | Полный путь, ID из JSON или однозначное имя ноды. Для одной ноды можно опустить. |
| `title`, `subtitle` | Строка или объект `{ru, en}`. |
| `fields` | Имена параметров, полные ID или объекты настроек. Порядок списка задаёт порядок строк. Без списка выводятся доступные поля, кроме служебных компонентов рамп, кнопок, labels и folder sets. |
| `placement` | `left`, `right`, `below`, `overlay`. По умолчанию `right`. |
| `width` | Ширина в пикселях, по умолчанию 320. Для каждой боковой колонки ширину задаёт её первая панель. |
| `anchor` | Для overlay: `top-right`, `top-left`, `bottom-right`, `bottom-left`. |
| `x`, `y` | Произвольная позиция overlay: числа в процентах от области видео либо CSS-значения (`"2rem"`, `"calc(50% - 160px)"`). Заменяют anchor. Отсчёт от левого верхнего угла панели. |
| `theme` | `dark` или `light`. |
| `variant` | `table` или `cards`. |
| `rowHeight` | Минимальная высота строки таблицы в пикселях: 24–120, по умолчанию 44. Длинная подпись или рампа могут увеличивать строку, чтобы содержимое не обрезалось. В режиме карточек не применяется. |
| `accent` | CSS-цвет акцента. |
| `precision` | Максимум знаков после запятой для чисел (по умолчанию 2). |
| `showHidden` | По умолчанию `false`: скрытые в Houdini поля не показываются. `true` позволяет показывать специально выбранные поля независимо от этих состояний. |
| `showFrame` | Показывать номер исходного кадра в заголовке (по умолчанию `true`). |
| `colorSpace` | `srgb` (по умолчанию) или `linear`: простое linear RGB → sRGB для цветовых образцов и градиентов. Не является OCIO-преобразованием. |
| `style` | React style-объект для панели. Можно менять CSS-переменные `--hda-bg`, `--hda-text`, `--hda-muted`, `--hda-border`, `--hda-row`. |

Можно добавить несколько панелей одной ноды или разных нод, например две
небольшие панели в разных углах видео. При нескольких нодах `node` должен быть
указан для каждой панели. Чтобы вынести слой в другую композицию страницы,
можно напрямую использовать `HdaParameterPanel` с подготовленным `bundle` и
`sampleIndex`; видеопроигрыватель и представление полей разделены.

На экранах уже 1024 px боковые панели переносятся под видео; уже 768 px overlay
тоже переходит под видео, сохраняя читаемость. Нативный полноэкранный режим самого
`<video>` показывает видео отдельно от DOM-панелей; для композиции с панелями
используй обычный просмотр страницы.

## Настройки отдельного поля

Вместо строки в `fields` можно передать объект:

```js
{
  name: "percent",
  label: { ru: "Удаление секций", en: "Section removal" },
  view: "bar",
  min: 0,
  max: 100,
  precision: 1,
  unit: "%",
  showHidden: true,
}
```

Поддерживаются `view: "auto" | "text" | "bar" | "color"`. `auto` выбирает
представление по типу Houdini. `text` принудительно показывает исходное значение,
например числовой токен меню. `bar` добавляет индикатор числового диапазона.
Для RGB/RGBA можно переопределить `colorSpace` у отдельного поля.
Состояния переключателей показываются чекбоксами без текстовых подписей;
чекбоксы служат индикаторами и не изменяют параметры.

Сами значения не редактируются. Изменение числа, цвета или состояния
подсвечивается кратким изменением яркости; дополнительного сглаживания значений
между сэмплами нет. При `prefers-reduced-motion` подсветка отключается.

Числовая рампа рисуется из вычисленного в Houdini профиля. Если профиль был
отключён, показываются исходные точки с пунктирным соединением и пометкой:
это не имитация сложных basis Houdini. Цветовой градиент из точек без профиля
также является линейной визуальной аппроксимацией.

## Связь времени с видео

Формула:

```text
sourceTime = (videoTime - videoStart) * speed + sourceStart
```

`sourceTime = 0` — первый кадр JSON, даже если в Houdini это кадр 1001.
Все времена задаются в секундах. `videoStart: 2` означает, что демонстрация
параметров начинается на второй секунде видео. До начала значения не выводятся.
После последнего сэмпла удерживается последнее состояние.

Основной источник времени — `requestVideoFrameCallback` и `mediaTime`
показанного кадра. Для браузеров без этого API предусмотрен `requestAnimationFrame`
с чтением `currentTime`. Пауза, перемотка в обе стороны, изменение скорости
видео и loop не запускают независимую анимацию параметров.

Видео воспроизводится обычным HTML-плеером из исходного файла.
При включённом `loop` ролик начинается заново и идёт вперёд.
Пауза и перемотка используют стандартные элементы управления браузера.
Панель HDA синхронизируется с временем реально показанного видеокадра.

Для монтажа укажи сегменты:

```js
sync: {
  segments: [
    { videoStart: 0, videoEnd: 4, sourceStart: 0, speed: 1 },
    { videoStart: 5, videoEnd: 9, sourceStart: 8, speed: 0.5 },
    { videoStart: 9, videoEnd: 11, sourceStart: 10, speed: 0 },
  ],
}
```

Сегменты идут по возрастанию времени, не перекрываются и включают начало,
исключая конец. Между сегментами данные не выводятся. `speed: 0` удерживает кадр,
отрицательная скорость позволяет показать обратный ход исходной анимации.

При смене состава multiparm чтение выполняется через актуальный layout.
Удалённые экземпляры не остаются в таблице. Неизвестные/неисправные данные
отображаются как «Нет данных», а не как последнее успешное значение.

## Проверки

```powershell
npm run test:hda
npm run build
```

Тесты проверяют чтение разреженных дорожек, перемотку, multiparm, меню,
преобразование RGB, карту времени, паузу, loop и очистку видеоподписок.
Если в `houdini-exports.local` есть комплект `buildingHDAdemo`, дополнительный
тест сравнивает все его кадры с Python-декодером исходного экспортёра
(для этой дополнительной проверки требуется команда `python`). Без локального
комплекта эта проверка пропускается, остальные используют небольшой fixture.
